# 2026년 2학기 웹응용 프로젝트: 미림 동아리 홍보

동아리를 조회하고, 상세 설명을 확인한 뒤 신청할 수 있는 동아리 홍보 및 관리 웹 서비스입니다.

## 주요 기능

- 동아리 조회, 등록, 수정, 삭제
- 동아리 신청
- 동아리 상세 페이지
- 사용자 밴 처리

## 사용 기술

- HTML, CSS, JavaScript
- localStorage
- Supabase
- Git

## 실행 방법

1. 저장소를 클론합니다.

   ```bash
   git clone <저장소 주소>
   ```

2. 프로젝트 루트에 `env.js` 파일을 만들고 아래 내용을 입력합니다.

   ```js
   const env = {
     DB_URL: "supabase_url",
     DB_KEY: "supabase_key",
   };
   ```

3. `start_page.html`을 브라우저로 열거나 Live Server로 실행합니다.

## Commit 타입 가이드

| 타입 | 설명 |
|------|------|
| `feat` | 새로운 기능에 대한 커밋 |
| `fix` | 버그 수정에 대한 커밋 |
| `build` | 빌드 관련 파일 수정, 모듈 설치 또는 삭제에 대한 커밋 |
| `chore` | 그 외 자잘한 수정에 대한 커밋 |
| `docs` | 문서 수정에 대한 커밋 |
| `style` | 코드 스타일, 포맷 등에 관한 커밋 |
| `refactor` | 코드 리팩토링에 대한 커밋 |
| `test` | 테스트 코드 수정에 대한 커밋 |
| `perf` | 성능 개선에 대한 커밋 |
